# Calendar UX: Apple-style views, event editor, calendar management (exact app)

**Status:** ⏳ In Progress (Phases 1-2 done) | Tighten calendar tab like notes/tasks

## Principles (carried from notes/tasks)
- No inline draft rows: actions live in header buttons, ⋯ menu, floating "+" (bottom-right, AccentColor, 56px).
- Header: title + compact actions; period label + prev/next/Today; segmented Day/Week/Month.
- Plain lists (no card borders/dividers); color + Lucide icon (reuse `IconColorPicker`, `LucideIcon`, 15-color palette) per calendar.
- Modals for create ("New Event") reuse the full editor in create mode (`creating`), like `TaskEditor`.
- Multi-line fields grow (`field-sizing="content"`); one scroll container per form; no popovers for low inputs (iOS keyboard shim, see notes/rich-text.md "Keyboard").
- Rows sized by content; Apple-like: month dots in event color, selected day agenda under the grid, Day view = hour timeline.
